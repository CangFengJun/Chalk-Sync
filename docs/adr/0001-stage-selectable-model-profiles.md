# Use stage-selectable local model profiles and native Responses transports

ChalkSync assigns an independent local model profile to the Worker Stage and Final Stage, defaulting to DeepSeek for worker evidence and GPT for final notes while permitting either profile at either stage. A checked-in profile runner reads only the ignored `ds.env` and `gpt.env` files; ChalkSync does not read Codex or DeepSeek Harness configuration and does not retain the previous generic environment-variable interface. Both profiles use their native Responses endpoints, with provider-aware system instructions, reasoning effort, structured worker output, and DeepSeek-only image normalization. Generated artifacts record non-secret profile provenance: a mismatch stops without spending API credit until forced regeneration is explicitly requested, and invalidation follows stage dependencies rather than discarding unaffected upstream work.
